# 通しバランスレポート（α20）

`game/balance.ts` の決定論ハーネスで、標準軍が戦場1→6（両分岐）を通しプレイした集計。

## 前提（ヘッドレス・AIベースライン）
- プレイヤー操作なし。味方隊は接近AI（`front`）、**大将隊は後置 `rear`**（実プレイヤー同様に温存）。
- **必殺技・必殺技アイテムは未使用**（雷光・象封じ等を撃たない＝悲観的評価）。実プレイヤーはこれらで更に有利。
- 戦闘間は全回復（回復薬/休息の運用を想定）。XP・レベルアップ・援軍は本番同様に適用。
- 30シードで集計。

## 結果（30シード）

| 戦場 | 勝率 | 平均決着 | 平均味方生存 |
| --- | --- | --- | --- |
| 戦場1・平原の遭遇戦 | 100% | 4.8s | 4.0 |
| 戦場2・森の伏撃 | 100% | 11.3s | 4.0 |
| 戦場3・山道の決戦（マゴ入軍） | 100% | 12.5s | 7.0 |
| 戦場4A・平原の追撃 | 100% | 8.4s | 9.0 |
| 戦場4B・河の防衛線 | 100% | 7.8s | 9.0 |
| 戦場5・湿地の戦象 | 100% | 8.4s | 11.0 |
| 戦場6・決戦 スキピオ | 93–97% | 10.6s | 10.5 |
| **全クリア率** | **93–97%**（両分岐） | | |

## 所見
- 難易度は緩やかに上昇（決着 4.8s→12.5s、終盤も10s前後でテンポ良好）。
- **唯一の山場は戦場6**（スキピオ＝学び＋象無効化、戦象2体）で 3–7% の敗北。AIベースラインでこの数値なら、必殺技・象封じを使う実プレイヤーには適切な手応え。
- 援軍（戦場3=マゴ＋2、戦場4A/4B=2、戦場5=2）で味方戦力が敵の増加に追従し、人数負けを回避。

## ハーネスが検出・是正した点
- 当初 全クリア率 0%。原因は ①中盤の援軍不足 ②**大将がHP1で持ち越され即死**（回復未モデル）。
- ①→ 戦場4A/4B/5 に援軍2名を追加。②→ 戦闘間の全回復を前提化（プレイヤーの回復運用に合わせた）。

## 使い方（再計測）
`summarize(seeds, path)`（`game/balance.ts`）を esbuild でnode実行。数値（兵士/装備/必殺技/敵編成）を
変えて勝率・決着の速さの変化を観測する。決定論なのでシード固定で完全再現。
